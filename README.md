# The Daily New Subscription

A static news-subscription landing page template — "The Daily Chronicle" — a news homepage with a hero section, article cards, subscription pricing tiers, and a dark footer. Built as a single self-contained HTML file, styled with Tailwind CSS via CDN.

## Features

- Hero banner section with breaking-news background imagery
- Category-tagged article cards (World, Politics, Business, Tech, Culture)
- Subscription pricing cards (Free / Monthly / Yearly style tiers) with a "Most Popular" highlight badge
- Monthly/yearly billing toggle switch
- Dark footer with navigation links
- Responsive layout via Tailwind CSS utility classes
- Zero build step — open `index.html` directly in any browser

## Tech Stack

- HTML5 + CSS3
- Tailwind CSS (CDN)
- Font Awesome icons
- Google Fonts (Inter)

## Quick Start

```bash
git clone https://github.com/girishlade111/The-Daily-new-subscription.git
cd The-Daily-new-subscription
# No build or dependencies — just open the file:
open index.html   # or double-click it
```

Or serve it locally with any static server:

```bash
npx serve .
```

Static single-page site. Deploy free on GitHub Pages: Settings → Pages → Deploy from branch `main` → `/ (root)`, or host anywhere static (Netlify, Cloudflare Pages, Vercel).
